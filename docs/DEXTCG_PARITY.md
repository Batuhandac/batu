# Cardory DexTCG Parity

Source reviewed: https://dextcg.com/

## Covered Now

- Camera scanner: server-side GiblTCG, PokemonTCG, Anthropic and visual verification gate.
- Expansions: Pokemon set browser with game and region filters for International, Japan and China.
- Card variants: normal, holofoil, reverse holofoil, first edition holofoil and first edition normal.
- Multiple markets: primary price, TCGPlayer, Cardmarket, eBay lookup infrastructure and Turkey TRY estimate.
- Friends and comparison: friends surface plus trade graph foundation.
- Stats everywhere: collection value, game distribution, rarity, condition and top cards.
- Custom folders: manual folders in store.
- Smart folders: high value, duplicates, foil, missing price and noted cards.
- Deck builder: Pokemon 60-card readiness, type buckets and copy-limit warnings.
- Card notes: editable notes on owned card detail.
- Badges/challenges: handcrafted collection, value, scan, social and Pokedex challenges.
- Refined search: collection query, game, condition, finish, value, rarity/set sorting and multilingual aliases.
- Widget readiness: snapshot builder for total cards, smart folders and most valuable card.
- Themes/icons readiness: settings surface and theme constants.
- Push notification readiness: settings surface and event types in ops/data moat.
